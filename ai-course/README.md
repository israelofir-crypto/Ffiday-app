# 🤖 קורס AI

מרכז אישי לקורסי בינה מלאכותית שנבחרו — חלק נפרד מהמאגר, בלי קשר
לאפליקציית "שישי בבוקר".

🌐 **כתובת:** https://israelofir-crypto.github.io/Ffiday-app/ai-course/

## מה יש כאן

- **ארבעה קורסים עם פירוק מלא** — הטכניון, בר-אילן, תפנית (האו"פ) והעברית: כל נושא בסילבוס,
  מה לומדים בו, דוגמה ממחלקת הכספים ורמת הרלוונטיות לכספים.
- **גרף שעות** לכל קורס לפי נושא, צבוע לפי רלוונטיות לכספים.
- **עדשת כספים** — טבלה של 11 משימות כספים מול ארבעת הקורסים וציון מצטבר.
- **ציון התאמה ונימוק** לכל קורס, בעד ונגד, פרטים (שעות, מחיר, פתיחה, תנאי קבלה).
- **הוספת קורסים, שינוי סטטוס וחיפוש** — נשמרים בדפדפן (localStorage).

## קבצים

`index.html` — קובץ אחד עצמאי: כל נתוני הקורסים מוטמעים בו, בלי תלויות ובלי build.
פותחים אותו ישירות בדפדפן, גם בלי שרת.

קישור ישיר לנושא: `index.html#technion-nocode`, `#barilan-claude-code`,
`#tafnit-ai-leaders`, `#huji-ai-developer`, או `#finance` לעדשת הכספים.
