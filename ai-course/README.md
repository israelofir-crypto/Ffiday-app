# 🤖 קורס AI

מרכז אישי לקורסי בינה מלאכותית שנבחרו — חלק נפרד מהמאגר, בלי קשר
לאפליקציית "שישי בבוקר".

🌐 **כתובת:** https://israelofir-crypto.github.io/Ffiday-app/ai-course/

## מה יש כאן

- **דשבורד** — מספר קורסים, כמה הושלמו, כמה בתהליך ופילוח לפי נושא.
- **חיפוש וסינון** — לפי טקסט, נושא, רמה וסטטוס.
- **הוספת קורס** — טופס בתוך האפליקציה. הקורסים נשמרים בדפדפן.
- **חיפוש קורסים חדשים** — קיצורי חיפוש ב-Coursera, Udemy, YouTube ו-Google.
- **ייצוא / ייבוא** — שמירת הרשימה כקובץ JSON והעברה בין מכשירים.

## קבצים

| קובץ | תפקיד |
|------|-------|
| `index.html` | האפליקציה כולה (ללא תלויות וללא build) |
| `courses.json` | רשימת קורסי הבסיס שמוצגת לכל מי שנכנס |

קורסים שנוספו מהטופס נשמרים רק בדפדפן שבו הוספו. כדי שיופיעו לכולם,
מייצאים JSON ומעדכנים את `courses.json` במאגר.

## מבנה קורס

```json
{
  "id": "unique-id",
  "title": "שם הקורס",
  "provider": "Coursera",
  "url": "https://...",
  "topic": "LLM",
  "level": "מתחילים",
  "status": "מתוכנן",
  "language": "עברית",
  "notes": "הערות"
}
```

`status` הוא אחד מ: `מתוכנן`, `בתהליך`, `הושלם`.
`level` הוא אחד מ: `מתחילים`, `בינוני`, `מתקדמים`.
